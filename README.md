# Blocks — прототип блокового конструктора сайтов

Минимальный визуальный редактор страниц в духе Tilda (блоковый подход, «вариант 1»):
пользователь собирает страницу из готовых блоков, редактирует содержимое в панели
свойств и экспортирует готовый статический HTML.

Без зависимостей и сборки: чистые HTML/CSS/JS.

## Запуск

Откройте `index.html` в браузере — этого достаточно. Для удобства можно поднять
локальный сервер:

```bash
npx serve .
```

## Возможности

- Библиотека из 11 блоков: обложка, заголовок, текст, карточки, галерея,
  изображение, FAQ, призыв к действию, колонки (2/3/4 с любым содержимым),
  отступ, футер.
- Гибкая вёрстка: блок «Колонки» строит сетку из 2/3/4 колонок (на мобильных
  складывается в одну), а в секции «Стиль блока» для любого блока доступны
  отступы сверху/снизу, ширина и высота.
- Canvas с живым рендером страницы, выделение блока кликом.
- Drag-and-drop с предпросмотром (WYSIWYG): блоки перетаскиваются как внутри
  страницы для переупорядочивания, так и из библиотеки прямо на canvas — при
  перетаскивании исходный блок схлопывается, а его полупрозрачная копия
  («призрак») показывает будущую позицию; лёгкий сдвиг без наведения на другой
  блок ничего не меняет.
- Inline-редактирование (WYSIWYG): двойной клик по заголовку, тексту, подписи,
  кнопке или футеру включает редактирование прямо на странице (для текстового
  блока — с форматированием и санитизацией).
- Переупорядочивание кнопками ↑/↓, дублирование и удаление блоков.
- Панель свойств: тексты, ссылки, цвета, выравнивание, повторяющиеся списки
  (карточки, галерея, вопросы FAQ) с добавлением/удалением/сортировкой элементов.
- Rich-text в текстовых блоках: жирный, курсив, подчёркивание, зачёркивание,
  ссылки, очистка форматирования (contenteditable + execCommand). Вводимое HTML
  проходит санитизацию: удаляются `script`/`iframe`/`style`, `on*`-обработчики
  и `javascript:`-URL.
- Панель «Слои»: дерево «страница → блоки → вложенные элементы» (родитель–потомок);
  клик выбирает блок на canvas, клик по вложенному элементу подсвечивает его
  карточку в панели свойств.
- Секция «Стиль блока» для любого блока: ширина, высота, скругление углов,
  выравнивание, шрифт, палитра из 6 готовых сочетаний, цвета фона и текста, прозрачность,
  тени (4 пресета) и эффекты (ч/б, размытие, сепия, ярче). Стиль применяется
  и в предпросмотре, и в экспорте HTML.
- Шрифты: подключение любого шрифта из Google Fonts по названию и загрузка
  шрифтового файла с компьютера (`.ttf/.otf/.woff/.woff2`) — файл встраивается
  в экспорт как data-URL, экспорт остаётся самодостаточным. Можно назначить
  шрифт всему сайту или отдельному блоку.
- Undo/redo (Ctrl+Z / Ctrl+Shift+Z), Delete для удаления выбранного блока.
- Режим «Превью» и переключатель desktop/mobile.
- Двуязычный интерфейс RU/EN: переключатель в тулбаре, выбор сохраняется
  в localStorage (при смене языка страница перезагружается).
- Несколько страниц: селектор в тулбаре, добавление и удаление страниц,
  переименование через поле названия; демо-сайт состоит из двух страниц.
- Автосохранение в localStorage (формат v2: `{ pages, currentPageId }`,
  данные v1 мигрируют автоматически).
- Экспорт: самодостаточный `index.html` текущей страницы (CSS инлайнится в
  файл), «Экспорт сайта» — один `index.html` со всеми страницами, навигацией
  и hash-роутингом между ними; `site.json` со схемой всех страниц; импорт
  JSON понимает форматы v2 (сайт), v1 (страница) и старый массив блоков.

## Архитектура

```
[Библиотека блоков]  →  [JSON-схема страницы]  →  [Рендер в HTML]
     (blocks.js)         (state в editor.js)        (render + buildHtml)
```

- `js/blocks.js` — каталог типов блоков. Каждый тип описан декларативно:
  `name`, `icon`, `defaults()` (начальные пропсы), `fields` (описание полей
  для панели свойств: text/textarea/color/select/range/items) и `render(props)`
  (HTML блока). Новый тип блока = один объект в этом каталоге, UI подхватит
  его автоматически.
- `js/site-css.js` — стили блоков (`SITE_CSS`). Используются и в редакторе,
  и при экспорте, поэтому превью всегда совпадает с результатом.
- `js/i18n.js` — словарь интерфейса (RU/EN) и функция `t(key, vars)`;
  статические элементы HTML размечены атрибутами `data-i18n`,
  `data-i18n-placeholder` и `data-i18n-title`.
- `js/editor.js` — состояние страницы (`{ title, blocks: [{id, type, props}] }`),
  история изменений, рендер canvas и инспектора, drag-and-drop, экспорт/импорт.
- `css/editor.css` — оформление самого редактора (в экспорт не попадает).

## Публикация на GitHub Pages

1. В редакторе нажмите «Экспорт сайта» — скачается один файл `index.html`
   со всеми страницами сайта и переключением между ними.
2. В репозитории создайте ветку `gh-pages` и положите файл в корень как
   `index.html` (для демо-контента можно просто выполнить
   `node scripts/build-demo.js` — он соберёт `dist/index.html`).
3. Включите Pages: Settings → Pages → Source: ветка `gh-pages`, папка `/ (root)`.
4. Сайт будет доступен по адресу `https://<owner>.github.io/<repo>/`.

## Ограничения прототипа

- Один пользователь, один сайт, хранение в localStorage.
- Нет публикации на хостинг, форм и интеграций.
- Rich-text — легковесный (execCommand): нет списков, таблиц и загрузки
  изображений внутрь текста; для этого понадобится TipTap/ProseMirror.
